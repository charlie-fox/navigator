# 个人导航页面

一个轻量级的个人网站导航页面，集成搜索功能，优化了低配置设备的使用体验。

## 功能特性

- **集成搜索**: 支持必应和谷歌搜索，可直接在页面进行搜索
- **性能优化**: 专门针对低配置设备优化，减少动画和特效开销
- **响应式设计**: 支持桌面和移动设备自适应布局
- **智能tooltip**: 鼠标悬停显示网站详细说明
- **优雅配色**: 深色背景配合浅色卡片，护眼舒适

## 网站分类

### 左侧栏
- 🔍 **搜索**: 必应、百度、Google等主流搜索引擎
- 📧 **办公**: WPS Office、Office 365、飞书、腾讯文档、邮箱服务

### 主内容区
- 💬 **社交**: 微博、知乎、小红书、豆瓣、Twitter等社交平台
- 🤖 **AI**: 通义千问、Kimi、豆包、DeepSeek、ChatGPT、Gemini等AI助手服务
- ☁️ **云服务**: Oracle Cloud、CloudFlare等云计算和网络安全服务
- 🛠️ **工具**: 地图导航、云存储、开发工具、设计工具、笔记应用
- 🏠 **生活**: 淘宝、京东、12306、携程、支付宝、美团等生活服务
- 🎬 **娱乐**: 哔哩哔哩、抖音、腾讯视频、爱奇艺、网易云音乐、YouTube等

## 设计原则

- **国产优先**: 各分类中国产服务排在前面，国际服务排在后面
- **类型聚合**: 同类型服务（如AI视频工具）放在一起
- **流行程度**: 按使用频率和流行程度排序

## 使用方法

1. 将 `navigator.html` 文件保存到本地
2. 在浏览器中打开该文件
3. 将其设置为浏览器主页即可

## 性能优化

- 低配置设备自动禁用动画和特效
- 低分辨率屏幕简化阴影效果
- 移动设备优化触摸交互
- 单文件设计，无外部依赖

## 自定义

可以根据个人需求修改HTML文件中的链接，添加或删除网站，调整分类。所有样式和脚本都在单个HTML文件中，便于修改和分发。
